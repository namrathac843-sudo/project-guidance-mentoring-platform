Settings

Manage your theme, password, notifications, and account.

Appearance

Your theme preference is saved in this browser and applied immediately.

Notification preferences

Toggle which in-app notifications you want to receive.

  • Project activity Submissions, reviews, approvals, and rejections
  • Mentoring requests New requests and responses
  • Session updates Scheduling, rescheduling, cancellation
  • Messages New in-app messages from other users

These toggles only affect what is displayed inside this demo. No real emails or push notifications are sent.

Change password

You will remain logged in after changing your password.

Account

Actions below affect only this browser's local records and the server's in-memory store. See the README for the exact limits.

Log out Clear your active session on this browser.
Reset demonstration data Deletes every pgmp_* key in this browser. Use this when you want a fresh demo. Server-side in-memory data is not touched.
Delete this account Removes your user record, projects, requests, sessions, and messages from this browser and the server's in-memory store.
